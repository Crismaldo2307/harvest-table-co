# Harvest Table Co.

A modern Next.js 14 web experience for Harvest Table Co., a premium catering partner blending culinary excellence with intelligent technology. The project is optimized for Vercel deployments and includes a ready-to-wire CRM flow via n8n.

## Tech Stack

- [Next.js 14](https://nextjs.org/) with the App Router
- [React 18](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) for subtle animations

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Duplicate the `.env.local.example` file and rename it to `.env.local`. Provide the real values for:

- `N8N_WEBHOOK_URL`: The webhook URL generated by your n8n workflow that stores leads in Google Sheets.
- `OPENAI_API_KEY`: Placeholder for the future AI integration (not consumed yet).

### 3. Run the development server

```bash
npm run dev
```

The site will be available at [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
npm start
```

## Deployment on Vercel

1. Push this repository to GitHub.
2. Create a new project in Vercel and import the GitHub repo.
3. Set the environment variables in the Vercel dashboard (`N8N_WEBHOOK_URL`, `OPENAI_API_KEY`).
4. Deploy—Vercel will detect the Next.js app automatically.

## Connecting the n8n Webhook

1. Create an n8n workflow that starts with a **Webhook** node (POST method).
2. Copy the webhook URL into the `N8N_WEBHOOK_URL` environment variable.
3. In the workflow, add nodes to format and send the data to Google Sheets (or your preferred CRM).
4. Publish the workflow. Every submission from the quote form will POST to this webhook with the following payload:

```json
{
  "name": "Alex Morgan",
  "email": "alex@company.com",
  "eventType": "Corporate Summit",
  "eventDate": "2025-05-18",
  "guests": "120",
  "message": "Looking for premium tapas and bar service.",
  "submittedAt": "2025-04-12T18:25:43.511Z"
}
```

## AI Sales Agent Demo

- The floating chat widget is pre-wired to call `/api/agent`.
- The endpoint currently returns a placeholder response and the UI falls back to curated demo data located in `src/data/demo-data.json`.
- Replace the placeholder logic with your preferred AI provider by updating `src/app/api/agent/route.ts` to call the real model (for example, OpenAI or an n8n workflow).
